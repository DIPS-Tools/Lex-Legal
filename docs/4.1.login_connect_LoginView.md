login.html connects to LoginView.vue through Vue’s external template declaration:

<template src="../../templates/login.html"></template>

This line is at the bottom of lex-legal_frontend/src/views/LoginView.vue:50.

It means:

LoginView.vue script logic
        +
templates/login.html markup
        =
one Vue component

## 1. LoginView.vue imports the HTML template

lex-legal_frontend/src/views/LoginView.vue:1 has two component sections:

<script setup lang="ts">
// Component state and functions
</script>

<template src="../../templates/login.html"></template>

The src path is resolved relative to LoginView.vue:

src/views/LoginView.vue
  ../../
templates/login.html

During Vite compilation, Vue reads lex-legal_frontend/templates/login.html:1 and uses it as the template for LoginView.vue.

## 2. <script setup> exposes values to login.html

Variables and functions declared in <script setup> are automatically available inside the component’s template.

For example, LoginView.vue defines:

const username = ref('')
const password = ref('')
const submitting = ref(false)

const submit = async () => {
// Login logic
}

Therefore, login.html can use them directly:

<input v-model="username" />
<input v-model="password" />

<form @submit.prevent="submit">

You do not need to export them manually.

## 3. The inputs update Vue variables

The username input contains:

<input
v-model="username"
autocomplete="username"
/>

Vue treats this approximately as:

<input
:value="username"
@input="username = event.target.value"
/>

The password input works in the same way:

<input v-model="password" type="password" />

Therefore, while the user types:

Username input → username.value
Password input → password.value

## 4. Clicking Sign in submits the form

The button is:

<button type="submit">
Sign in
</button>

Because it has type="submit" and is inside the form, clicking it produces the browser’s form submit event.

The form handles that event here:

<form class="login-form" @submit.prevent="submit">

This has three parts:

- @submit listens for the form’s submit event.
- .prevent calls event.preventDefault().
- submit calls the submit() function from LoginView.vue.

Without .prevent, the browser would reload the page and perform a traditional HTML form submission.

The effective flow is:

Click Sign in
  ↓
<button type="submit">
  ↓
<form> emits submit event
  ↓
@submit.prevent
  ↓
LoginView.vue submit()

## 5. LoginView.vue calls the login service

The submit() function reads the current Vue values:

const submit = async () => {
if (!username.value.trim() || !password.value || submitting.value) return

submitting.value = true
errorMessage.value = ''

try {
  const user = await login(username.value, password.value)
  password.value = ''
  await router.replace(destinationFor(user.is_admin))
} catch (error) {
  errorMessage.value = error instanceof Error
    ? error.message
    : 'Unable to sign in.'
} finally {
  submitting.value = false
}
}

It calls:

login(username.value, password.value)

The login() function was imported at the top:

import { login } from '../services/auth'

The calling chain is therefore:

templates/login.html
  @submit.prevent="submit"
           │
           ▼
views/LoginView.vue
  submit()
           │
           ▼
services/auth.ts
  login(username, password)
           │
           ▼
fetch("http://server:8008/api/auth/login")

## 6. Reactive values update the template automatically

While the request is running:

submitting.value = true

The HTML automatically changes because it uses:

:disabled="submitting || !username.trim() || !password"

and:

{{ submitting ? 'Signing in…' : 'Sign in' }}

If login fails:

errorMessage.value = error.message

This element becomes visible:

<p v-if="errorMessage" class="login-error">
{{ errorMessage }}
</p>

If login succeeds, Vue Router opens the requested page.

In short, the connection is created by:

<!-- LoginView.vue -->
<template src="../../templates/login.html"></template>

and the click is connected to the function by:

<!-- login.html -->
<form @submit.prevent="submit">

where submit() is declared inside LoginView.vue.
