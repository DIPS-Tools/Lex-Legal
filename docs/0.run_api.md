# Backend

```bash
uvicorn app.api.lex_legal_api:app --host 0.0.0.0 --port 8008
```

Open `http://localhost:8008/docs` for both Legal Compliance APIs and Legal
Document Import APIs.

# Frontend

cd lex-legal_frontend
npm ci
npm run dev -- --host 0.0.0.0 --port 5176
